# 在线部署

## 1. GitHub Pages

仓库推送到 GitHub 后：

1. 打开仓库 `Settings → Pages`。
2. Source 选择 `GitHub Actions`。
3. 运行 `Deploy web app` 工作流。
4. 网站地址通常是：

```text
https://你的用户名.github.io/仓库名/
```

静态网站支持：

- 书签文件解析
- 链接结构分析
- 跟踪参数清理
- 重复链接识别
- 本地导出
- PWA 离线壳

## 2. Python BFF

选择 Render、Railway、Fly.io 或任意 Docker 平台，使用项目根目录的 `Dockerfile`。项目已经提供 `render.yaml`，在 Render 中新建 Blueprint 并连接仓库即可。

部署时检查：

```text
GET /api/health
```

返回 `ok: true` 即表示接口工作。

## 3. 连接前后端

在 `web/config.js` 填写 HTTPS 后端地址：

```js
window.LINK_KEEPER_API = "https://linkkeeper-api.onrender.com";
```

提交后 GitHub Pages 会自动重新部署。页面顶部显示“在线深检 · 已连接 BFF”时，HTTP 状态检查才真正启用。

## 4. 生产安全

- 静态前端不能包含任何密钥。
- 为扫描 API 增加登录、速率限制和访问来源校验。
- 使用受控出口代理固定 DNS 结果，完整防御 DNS rebinding。
- 不要允许用户扫描隐私页面或不公开的内部 URL。
- 扫描任务当前存储在内存，服务重启后会丢失；生产版可接入 Redis 或 SQLite。
